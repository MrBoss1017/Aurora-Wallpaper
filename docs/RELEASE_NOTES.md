# Aurora Wallpaper 0.1.1 — Windows preview

A standalone Windows live wallpaper app with a setup wizard.

## Install

Download **AuroraWallpaper-Setup-0.1.1-x64.exe** below and double-click it. The wizard installs the app and required components, with optional desktop and sign-in shortcuts. No developer tools are needed.

Requires Windows 11 x64 or Windows 10 22H2 x64. The installer is unsigned; Windows may show an unknown-publisher warning. The matching `.sha256` file and `build-receipt.json` identify the downloaded build.

## Included

- MP4/WebM video, interactive web bundles, and Direct3D 11 shader wallpapers.
- Independent monitor wallpapers or a spanning scene.
- Fullscreen pause, battery and window coverage rules, audio controls, and system tray.
- Aurora Ribbon and Quiet Orbit sample wallpapers.
- Per-user installation and a standard Windows uninstaller.

## Preview limitations

Automated checks cover Windows compilation, 517 policy checks, setup installation, dependency loading, hidden application startup, and uninstallation. They do not establish compatibility with every Explorer version, GPU, multi-monitor layout, or video codec. See the repository's validation matrix. Desktop parenting relies on undocumented Explorer behavior.
